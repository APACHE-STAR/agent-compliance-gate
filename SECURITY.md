# Security Policy

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue.

Use GitHub's private vulnerability reporting:
**[Security → Report a vulnerability](https://github.com/APACHE-STAR/agent-compliance-gate/security/advisories/new)**.

This is the only channel for security reports. Please do not send them by email:
our general inbox is processed with AI assistance, and a report should never pass
through a third-party model.

We aim to acknowledge reports within a few business days. Thank you for helping
keep autonomous agents safe.
